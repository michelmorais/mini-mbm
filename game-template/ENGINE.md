# mini-mbm engine runtime

This file was generated by `copy-game-template.sh` or `copy-game-template.bat`.
The game project contains Lua scripts and assets; the engine executable and its
plugins stay in the engine checkout.

Engine binary directory:

`@ENGINE_BIN_DIR@`

@ENGINE_STATUS@

## Which runtime to use

Do not look for a system `lua`, `luajit`, or `lua5.4` when testing game code.
The Lua interpreter bundled with this engine is `lua-5.4.1.exe`, but it is only
appropriate for pure Lua modules. It does not register the engine's `mbm`
namespace or renderable tables. Game/API checks must run through the matching
`mini-mbm` binary so the real engine bindings are loaded.

## Recommended checks

From the game project root:

```sh
ENGINE_BIN="@ENGINE_BIN_DIR@"

# Fast structural check.
git diff --check

# Confirm that this project points to a usable Lua-enabled engine build.
test -x "$ENGINE_BIN/mini-mbm"

# Optional: pure-Lua checks can use the standalone bundled interpreter when present.
if [[ -x "$ENGINE_BIN/lua-5.4.1.exe" ]]; then
    echo "bundled Lua: $ENGINE_BIN/lua-5.4.1.exe"
fi

# Interactive run of the game's entry scene. Press Esc to leave it.
"$ENGINE_BIN/mini-mbm" --scene main.lua \
    --disable_select_monitor --nosplash -w 640 -h 480
```

On Windows, use the same recorded directory from PowerShell:

```powershell
$EngineBin = '@ENGINE_BIN_DIR@'
& "$EngineBin\mini-mbm.exe" --scene main.lua --disable_select_monitor --nosplash -w 640 -h 480
```

For an unattended Lua smoke test, use a temporary scene that calls
`mbm.quit()` after a short `mbm.getTimeRun()` deadline, then launch it with the
same `mini-mbm` command and wrap it in `timeout -s KILL` as a hard backstop.
Always pass `--disable_select_monitor`; otherwise the monitor/script picker can
block an automated run. Add `mbm.addPath(...)` before loading project assets.

Pure Lua-only checks may use the bundled interpreter explicitly:

```sh
"$ENGINE_BIN/lua-5.4.1.exe" path/to/pure-lua-test.lua
```

That command is not a substitute for testing a game script that uses `mbm`,
`sprite`, `mesh`, `font`, plugins, or other engine-registered tables.
